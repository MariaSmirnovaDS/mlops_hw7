# План A/B тестирования ML-модели

## Цель
Сравнить качество предсказаний текущей модели (v1.0.0) и новой (v1.1.0) на реальном трафике.

## Метрики
- Accuracy (точность)
- Время ответа API (latency)

## Параметры эксперимента
- Контрольная группа (A): model v1.0.0 – 70% трафика
- Экспериментальная группа (B): model v1.1.0 – 30% трафика
- Длительность: 7 дней
- Минимальный размер выборки: 1000 запросов на группу

## Критерий успеха
- Accuracy не ниже текущей (≥0.95)
- Latency не выше 200ms (p95)
- Отсутствие критических ошибок в /health

## Процедура
1. Балансировщик Nginx распределяет трафик 70/30
2. Логируются предсказания и метрики
3. Через 7 дней сравниваются результаты
4. При успехе – rollout до 100% новой версии
5. При неудаче – откат на старую версию
