# Сравнение стратегий деплоя Blue-Green и Canary для ML-модели

У меня есть ML-модель (RandomForest на iris dataset). Нужно обновить её с v1 на v2. Если новая модель хуже старой, пользователи не должны это заметить.

## Что сравнивала

**Blue-Green:**
- Две версии работают параллельно
- Балансировщик переключает весь трафик сразу
- Если новая версия не прошла health check — переключения нет
- Откат — просто переключить обратно

**Canary:**
- Сначала 10% трафика на новую версию
- Если всё хорошо — увеличиваю долю
- При ошибке 90% пользователей не пострадают

## Риски

| Стратегия | Главные риски |
|-----------|---------------|
| Blue-Green | health check может пропустить баг, тогда все пользователи получат плохую модель |
| Canary | 10% пользователей могут видеть ошибки, сложнее настроить автооткат |

## Мой выбор

**Blue-Green.**

Почему:
- Проще реализовать в домашнем задании
- Легко показать переключение
- health check напишу сама, так что риск контролирую

## Как будет работать

1. Blue = v1.0.0 (старая)
2. Green = v1.1.0 (новая)
3. Nginx переключает трафик между ними
4. Перед переключением проверяю /health
